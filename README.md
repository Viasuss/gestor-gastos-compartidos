# Proyecto: Gestion de gastos compartidos 
## 1. Problema que resuelve
cuando varias personas comparten gastos (arriendo, mercado, un viaje), se pierde la cuenta de quién pagó qué y quién le debe a quién, y terminan haciendo cálculos a mano en WhatsApp o Excel, lo cual genera errores y hasta peleas.
## 2. Usuarios objetivo
Grupos pequeños (2-6 personas) que comparten gastos de forma recurrente: roomies que pagan arriendo/servicios/mercado juntos, o grupos de amigos que viajan juntos y dividen hospedaje/comida/transporte.
## 3. Alcance MVP
se puede llevar: 
registro/login del usuario
crear un grupo(puede ser el plan del grupo)
agregar un gasto al grupo
calculo automatico(quien le debe a quien)
ver historial de gasto del grupo
## 4. Fuera de alcance (por ahora)
no van a ver notificaciones automaticas(correo/Push)
No va a hacer la simplificación inteligente de deudas (el algoritmo que minimiza transacciones, ej: en vez de que A le deba a B y B le deba a C, calcular que A le paga directo a C). 
no tenemos pensado en agregarle una app(por ahora), tenemos pensado en hacerla principalmente en una pagina web
no se pueden subir fotos de recibos ni comprobante
