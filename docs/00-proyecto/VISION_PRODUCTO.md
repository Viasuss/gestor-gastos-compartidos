# Visión del Producto — Partly

**Nombre provisional:** Partly (conservar hasta la fase final de identidad comercial; no realizar cambios de marca sin autorización).

---

## 1. Problema y evolución
Partly nació como un proyecto universitario para resolver el control de gastos compartidos en grupos pequeños (arriendo, mercado, viajes).

La nueva visión consiste en evolucionar el software hacia una **plataforma comercial de automatización financiera colaborativa**, orientada inicialmente a **hogares, parejas, estudiantes, amigos y grupos**, superando el concepto de agenda manual de gastos mediante herramientas inteligentes que reduzcan la intervención manual sin sacrificar precisión ni control humano.

## 2. Propuesta de valor
1. **Núcleo financiero determinista y confiable:** Cálculos exactos con `BigDecimal`, múltiples pagadores, múltiples modos de división, liquidaciones bilaterales y simplificación de deudas.
2. **Automatización inteligente con confirmación humana:** Captura de gastos desde lenguaje natural, notas de voz, facturas y comprobantes a través de una **Bandeja Inteligente** donde el usuario valida antes de persistir.
3. **Conectividad cotidiana:** Experiencia web instalable (PWA), notificaciones Web Push e integración con Telegram y compartición gratuita vía WhatsApp.
4. **Control y analítica:** Gastos recurrentes, recordatorios, presupuestos, metas compartidas, detección de anomalías y reportes exportables.
5. **Sostenibilidad económica (`$0 COP`):** Diseñado para operar con tecnologías abiertas y cuotas gratuitas controladas por un `ResourceManager`.
