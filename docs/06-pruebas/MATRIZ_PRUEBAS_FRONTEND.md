## 1. Convenciones de clasificación

| Tipo de prueba | Alcance y entorno |
|---|---|
| **Inspección estática** | Verificación automatizada sobre plantillas HTML/CSS del repositorio (pila de etiquetas, atributos, contratos y cálculo WCAG 2.1). |
| **Fixture HTML aislado** | Prueba **parcial** ejecutada en Microsoft Edge Headless (`--headless=new --dump-dom`) sobre copias extraídas fielmente del código intervenido con placeholders SSR mínimos (sin backend Spring ni BD). |
| **Prueba manual en navegador** | Verificación visual o interactiva realizada manualmente por un humano en navegador real (pendiente donde requiere servidor o inspección visual interactiva). |
| **Prueba MVC** | Pruebas `@WebMvcTest` / `MockMvc` sobre controladores y plantillas Thymeleaf (pendientes de integración `F1.1.A`). |
| **Prueba E2E** | Pruebas automatizadas de extremo a extremo contra instancia Spring Boot + H2 en memoria (pendientes de integración `F1.1.A` y `F1.7`). |

> **Regla de veracidad:** Ninguna prueba dependiente de Spring Boot, H2 o interacción humana pendiente se reporta como ejecutada.
